# ZoDo

A tiny, phone-first daily to-do list. Add tasks, tick them off, and enjoy the strike-through. Tasks are saved in this browser on this device. Each day gets a fresh list; older lists remain in browser storage but are not shown in the app.

## Run locally

Open this folder in VS Code. Use a local web server, such as the Live Server extension, and open the served address in your browser.

## Publish with GitHub Pages

Push this repository to GitHub. In Settings → Pages, choose Deploy from a branch, then select main and /(root). Open the Pages URL on your phone and optionally add it to your home screen.

This is a static site: no build command, account, or backend is needed. Clearing site data or switching devices removes access to that browser's list.
